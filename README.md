# 🪟 glassify – Modern Website Template

**glassify** is a modern and elegant HTML5/CSS3 template built for architecture firms, and construction studios.  
Designed with clean layouts, subtle animations, and responsive design principles, it’s perfect for showcasing services, portfolios, and contact information in a professional way.

---

## ✨ Features

- ✅ **Responsive Design** – Works seamlessly on desktop, tablet, and mobile.
- 🎨 **Modern Layout** – Clean typography and minimal design built with HTML5 and CSS3.
- 🧭 **Smooth Navigation** – Animated hamburger menu for mobile devices.
- 🧱 **Multi-Page Structure** – Includes:
  - `index.html` (Home)
  - `pages/studio.html` (Studio / About)
  - `pages/portfolio.html` (Portfolio)
  - `pages/contact.html` (Contact)
- 🖼️ **Image Assets Folder** – Ready to replace with your own company visuals.
- 🔤 **Bootstrap Icons Integrated**
- ⚙️ **Easy to Customize** – Simple file structure and well-commented code.

## 🚀 Getting Started

1. **Download or clone** the project:
   ```bash
   git clone https://github.com/yourusername/GlassCompany.git
   Open index.html in your browser to preview the homepage.
   ```

To customize, edit the HTML or the CSS files in the /css folder.

Replace images inside /glassImages with your own.

To deploy online, upload the entire folder to your hosting provider or use free platforms like Netlify, Vercel, or GitHub Pages.
